README — R Scripts for Proteomics Data Processing and Differential Expression Analysis
======================================================================================

OVERVIEW
--------
These four R scripts process label-free proteomics data generated by DIA-NN 2.0
and perform differential expression analysis (DEA) using the limma statistical
framework. Each script reads DIA-NN output files, applies filtering and
optional normalization/imputation, fits linear models to identify differentially
abundant proteins, and exports results as tables and/or volcano plots.

The scripts share a common analytical core but are configured for different
experimental designs, as described below.


SCRIPT DESCRIPTIONS
-------------------

1. General_Data_Analysis_Script.R
   Used for: Figures 2, 3, 5B–C, and S27

   This is the primary two-group comparison script. It compares a "positive"
   sample group against a "negative" (control) group — for example, cells sorted
   by a surface marker (CD3, CD4, CD8, CD20, CD45, MHC) versus their
   corresponding isotype control. The user defines which
   columns belong to each group by setting pos_column_names and neg_column_names
   in the configuration section. All data processed using the "uniform" option,
   which globally normalizes data using VSN. Imputation was not used and a threshold
   of one peptide was used for quantification.

2. Spatial_CD45_processing_model.R
   Used for: Figure 4D

   Designed for spatial proteomics experiments with a two-factor design:
   tissue type (e.g., B-cell vs. Th-cell) and antibody condition (Primary
   vs. Isotype control). This script uses an additive linear model
   (~ Tissue + Ab) fitted via limma, meaning it estimates the independent
   effects of tissue type and antibody condition without testing the interaction
   of the terms. Results are exported as an Excel file containing regression
   coefficients (Beta), raw p-values, and Benjamini–Hochberg adjusted q-values
   for each factor.

   For data in figure:
     - model_type was set to "additive"
     - min_peptides was set to 2
     - norm_mode and impute_mode were both set to "none"

3. Spatial_synapse_processing_model.R
   Used for: Figure 4E

   Similar to Spatial_CD45_processing_model.R, but
   configured with an interaction model (~ Tissue * Ab). This tests whether
   the antibody effect differs between tissue types (i.e., whether there is
   a statistically significant Tissue × Antibody interaction). The output
   includes Beta, p-value, and q-value columns for the tissue effect, antibody
   effect, and their interaction term.

   For data in figure:
     - model_type was set to "interaction"
     - min_peptides was set to 2
     - norm_mode and impute_mode were both set to "none" (log2 only)

4. EGFR_Aggregated_model.R
   Used for: Figure 5D

   Extends the spatial pipeline to handle data aggregated across seven patients.
   Each patient contributes two tissue blocks (Tumor and adjacent non-tumor
   tissue, labeled "Healthy"), each with Primary and Isotype antibody conditions.
   The 14 blocks (B01–B14) are defined in the configuration section and treated
   as a random/blocking effect via limma's duplicateCorrelation to account for
   inter-block variability.

   For data in figure:
     - model_type was set to "additive" (~ Tissue + Ab)
     - block_strategy was set to "block" (random effect via duplicateCorrelation)
     - missing_mode was "global" with max_missing_frac = 0.8
     - norm_mode and impute_mode were both set to "none" (log2 only)

SOFTWARE REQUIREMENTS
---------------------

Language:
  R (version 4.2 or later recommended)

Required R packages:
  - MSnbase      — mass spectrometry data structures, VSN normalization,
                   and MinProb imputation
  - limma        — linear modeling and empirical Bayes moderated statistics
                   for differential expression
  - DEP          — the make_unique() function for resolving duplicate gene names
  - dplyr        — data manipulation (filtering, joining, counting)
  - tidyr        — data reshaping (used in the spatial/EGFR scripts)
  - EnhancedVolcano — volcano plot generation (General script only)
  - writexl      — Excel export (spatial and EGFR scripts only)

Installation (run once in R):
  if (!requireNamespace("BiocManager", quietly = TRUE))
      install.packages("BiocManager")
  BiocManager::install(c("MSnbase", "limma", "DEP", "EnhancedVolcano"))
  install.packages(c("dplyr", "tidyr", "writexl"))


INPUT DATA
----------
All scripts expect DIA-NN 2.0 output in a single folder (the "working
directory"). The two key input files are:

  report.pg_matrix.tsv — Protein-group-level intensity matrix. Rows are
                          protein groups; columns include metadata fields
                          (Protein.Group, Genes, etc.) followed by one
                          intensity column per sample.

  report.pr_matrix.tsv — Precursor-level matrix, used to count unique
                          peptides per protein group for filtering purposes.

Refer to the Supplementary Information for the DIA-NN 2.0 search settings used to generate these files.


HOW TO RUN
----------

Step 1 — Set the working directory
  Open the script in RStudio (or any R environment) and set the
  working_directory (or wd) variable to the full file path of the folder
  containing your DIA-NN output files. For example:
    working_directory <- "C:/Users/yourname/data/experiment1"

Step 2 — Configure experimental groups
  For General_Data_Analysis_Script.R:
    - Set pos_column_names and neg_column_names to the column indices
      corresponding to your positive and negative sample groups.
    - Set pos_group_name and neg_group_name to descriptive labels (these
      appear in output filenames and plot axes).
    - Adjust PValue_cutoff and logFC_cutoff for volcano plot significance
      thresholds.

  For the spatial and EGFR scripts:
    - Edit the idx list within the CFG configuration block. Each top-level
      entry is a batch/block, and each sub-entry maps a "TissueType_Antibody"
      label to its column indices in the DIA-NN output.

Step 3 — Run the script
  Source the entire script in R:
    source("General_Data_Analysis_Script.R")
  Or highlight all code and run it in RStudio.

  The spatial and EGFR scripts call main() at the bottom of the file, which
  executes the full pipeline automatically.


OUTPUT FILES
------------

General_Data_Analysis_Script.R produces:
  - DEA_full_report_[pos]_vs_[neg]_[processing]_[replicates]_samples.csv
      Full differential expression results table including log2 fold changes,
      p-values, adjusted p-values, average expression, and per-sample
      normalized intensities.
  - RPlot_[pos]_vs_[neg]_[processing]_[replicates]_samples.tif
      Publication-quality volcano plot (5500 x 4000 px, 600 dpi, LZW
      compression).

Spatial and EGFR scripts produce:
  - An Excel file (name defined by out_file in CFG) containing a "stats"
    sheet with Beta coefficients, p-values, q-values (BH-adjusted), and
    -log10(p) values for each model term (Tissue, Antibody, and Interaction
    where applicable), along with per-sample expression values.


KEY CONFIGURABLE PARAMETERS
----------------------------

Parameter (General script)       Description
-------------------------------  -----------------------------------------------
do_imputation                    TRUE/FALSE — enable MinProb imputation
peptide_count_cutoff             Minimum unique peptides per protein (0 = no filter)
min_replicates                   Minimum non-missing values per group (integer or "all")
processing_type                  "separate_arms", "uniform", or "none"
PValue_cutoff                    P-value threshold for volcano plot coloring
logFC_cutoff                     Log2 fold-change threshold for volcano plot coloring
proteins_of_interest             Character vector of gene names to highlight on the plot
abundance_cutoff                 Minimum average expression to include in results

Parameter (Spatial/EGFR scripts) Description
-------------------------------  -----------------------------------------------
min_peptides                     Minimum unique peptides per protein
missing_mode                     "none", "global", or "per_arm"
max_missing_frac                 Maximum fraction of missing values allowed (0–1)
norm_mode                        "vsn_global", "vsn_by_group", or "none" (log2 only)
impute_mode                      "MinProb" or "none"
model_type                       "additive", "interaction", or "two_group" (EGFR only)
block_strategy (EGFR only)       "block" (random effect), "fixed", or "none"


NOTES AND TIPS
--------------
- Column indices in the group definitions (group_1, group_2, ... or the idx
  list) refer to column positions in the DIA-NN pg_matrix file. If your
  DIA-NN output has a different number of metadata columns or a different
  sample order, you will need to adjust these indices accordingly. Open the
  pg_matrix file in a spreadsheet editor and count the column positions to
  confirm.

- The data_identifier parameter in the General script should be set to a
  string that appears in all sample column headers (e.g., your initials or
  an instrument identifier). This is used to distinguish data columns from
  metadata columns.

- Zero values in the intensity matrix are automatically converted to NA
  (missing) before analysis, since a zero in DIA-NN output typically
  indicates that the protein was not detected in that sample.

- When do_imputation is FALSE (the default), proteins with missing values
  in some replicates are still included in the analysis. limma handles
  partial missingness internally. The min_replicates filter ensures each
  group has a minimum number of observed values.

- All scripts assume DIA (data-independent acquisition) input by default.
  The General script also contains a DDA path (data_type = "DDA")
  for FragPipe/combined_protein.tsv output, but DIA is the expected mode
  for the analyses described in this publication.

- For questions about the experimental design, DIA-NN search parameters,
  or biological interpretation, refer to the Methods and Supplementary
  Information sections.
